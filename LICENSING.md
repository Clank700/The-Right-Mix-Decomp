Limits that apply even inside this table:

* Some of these files contain **facts or strings that come from the game**: on-screen text, tuning numbers, identifiers, timing

## 2. Not under our MIT grant: `src/as2/`

`src/as2/` (40 ActionScript 2 sources, `hints.json`, `names.json`) is **reconstructed from the compiled game file**. It is derived from

* the game's own scripts (© their owners, see [`src/as2/NOTICE.md`](src/as2/NOTICE.md)).

Macromedia/Adobe's stock `mx.*` v2 component library, which the game file also embeds, is deliberately **not** published in this
repository; the build tool reuses it from the builder's own copy of the game.

We have no right to license that material, so **the MIT licence does not apply to anything in `src/as2/`**, and the copyright
notice in `LICENSE` does not extend to it. Our naming, comments and formatting inside those files do not change who owns the
underlying code. Read [`src/as2/NOTICE.md`](src/as2/NOTICE.md) before copying, reusing or redistributing any part of it.

The compiler that reads `src/as2/` (`tools/as2c/`) is ours and is MIT; the source it reads is not.

## 4. What a build produces

`python rightmix.py build --swf <your bartender.swf>` creates an app that contains the game's artwork, sound and animation, converted
from **your** copy. Those outputs are **not** covered by this licence in any way and must not be redistributed (this repository
never contains them). The tool does not make them redistributable.
