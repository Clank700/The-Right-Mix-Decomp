# the_right_mix (Flutter project)

Native ports of *The Right Mix* for Windows and Android. This folder contains the code only; the game's art and sound are extracted
from your own `bartender.swf` into `assets/` (git-ignored) by `python rightmix.py build ...` from the repository root.
See `../docs/PORT.md` for the design and `../docs/BUILDING.md` for how to build.
