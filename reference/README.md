# reference/

`original.json` holds the SHA-256 hashes (file and decompressed contents) and sizes of the original `bartender.swf` that the source in
`src/as2/` matches. It contains no game data. `rightmix.py` uses it to recognise your copy of the game and to verify the byte-identical rebuild.

## Source and title record

The working SWF copy used by this project was sourced from Flashpoint Archive. Its local SHA-256 is
`ede221ad99e031732a049409278ce45bc1602706045b95ab83756e72af8f23a7` (693,558 bytes). The Flashpoint Database record for
[The Right Mix](https://flashpointproject.github.io/flashpoint-database/search/#a64d77ab-bff7-c8f5-8c22-b6bd42343886) lists
`Bartender The Right Mix` as an alternate title. The record identifies the archived game entry; the SWF and any game assets are not
included here.
