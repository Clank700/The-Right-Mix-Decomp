This is a preservation / learning project. It is **not** affiliated with or endorsed by the owners of the game, and nothing here is
legal advice.

## The game

"The Right Mix" is a Flash game made for Land Securities by Liquid Light and Plugin Media. The game, its artwork, music, text and
branding belong to their owners. It also contains Macromedia/Adobe's stock "v2 components" (`mx.*`); **their source is not
published here**: the build tool keeps those 42 scripts as they are in the builder's own file.

**What this repository contains**

* decompiled ActionScript source (`src/as2/`) and the data needed to compile it back (`src/as2/hints.json`, `names.json`),
* tools we wrote (SWF project layer, assembler, compiler, asset converter, build/verification scripts),
* the Flutter ports as source code (`port/`), which re-implement the game's rules and contain its on-screen text and tuning numbers,
* documentation and test results (numbers, hashes and logs only).

**What it deliberately does not contain:** the game file (`bartender.swf`), any extracted or converted artwork, sound, font or
animation data, screenshots, icons rendered from the artwork, or any build that embeds them. `tools/publish_check.py` fails if
such files are about to be published. People build the ports from their own copy with `rightmix.py`.

The decompiled source and the ports' game logic are nevertheless derived from the original program. Publishing them is the
publisher's decision and responsibility; if a rights holder objects, remove the affected files.
